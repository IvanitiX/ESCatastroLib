# MapaValoresRusticosProvider

**Módulo:** `providers`

Provider para consulta de valores rústicos del Catastro.
Proporciona métodos para consultar los valores catastrales
de tierras y parcelas rústicas mediante el servicio WMS
del mapa de valores rústicos.
**Atributos:**

- `URL_BASE` — URL base del servicio WMS de valores rústicos.
