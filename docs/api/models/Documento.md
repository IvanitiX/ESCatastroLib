# Documento

**Módulo:** `models`

Documento asociado a una parcela catastral (croquis, plano, etc.).
**Atributos:**

- `url` — URL de descarga del documento.
- `descripcion` — Descripción del tipo de documento (ej. "Croquis catastral").


## Atributos

| Atributo | Tipo | Default |
|----------|------|---------|
| `url` | `str` | - |
| `descripcion` | `str` | - |
