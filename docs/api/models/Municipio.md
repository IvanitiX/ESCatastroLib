# Municipio

**Módulo:** `models`

Representa un municipio español con su provincia.
**Atributos:**

- `municipio` — Nombre del municipio.
- `provincia` — Nombre de la provincia.


## Atributos

| Atributo | Tipo | Default |
|----------|------|---------|
| `municipio` | - | - |
| `provincia` | - | - |
