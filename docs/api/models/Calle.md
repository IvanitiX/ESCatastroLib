# Calle

**Módulo:** `models`

Representa una calle dentro de un municipio.
**Atributos:**

- `municipio` — Municipio al que pertenece la calle.
- `tipo_via` — Tipo de vía (Calle, Avenida, Plaza, etc.).
- `calle` — Nombre de la calle según el Catastro.


## Atributos

| Atributo | Tipo | Default |
|----------|------|---------|
| `municipio` | `Municipio` | - |
| `tipo_via` | `str` | - |
| `calle` | `str` | - |
