# CalleMapper

**Módulo:** `composers/mappers`

Mapper para convertir DTOs de calle a modelos de dominio.
Transforma los DTOs de calles del Catastro en objetos Calle
del modelo de dominio, incluyendo el mapeo de tipos de vía.
